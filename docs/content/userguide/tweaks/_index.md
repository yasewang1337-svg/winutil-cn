“优化”页用于选择系统设置、检查当前状态、查看执行结果和恢复有记录的项目。先读清每项影响，再决定是否执行；不要把整个页面视为必须全部开启的设置清单。

## 选择方案

顶部方案按钮只改变勾选，不立即执行：

| 按钮 | 对应预设 | 当前内容 |
| --- | --- | --- |
| 基础设置 | Minimal | 减少推荐应用、增加任务栏结束任务入口 |
| 标准 | Standard | 基础设置，加活动历史策略和关闭 Windows 更新对等传输 |
| 高级 | Advanced | 标准方案，加创建还原点和经典右键菜单 |
| 清除 | — | 清除当前设置勾选 |
| 检查当前设置 | — | 尝试识别当前已应用的设置；检测结果不是历史快照 |

三个预设均不默认包含批量卸载应用或禁用服务。“高级”**包含创建还原点**。具体项目以本仓库的 [config/preset.json](https://github.com/yasewang1337-svg/winutil-cn/blob/main/config/preset.json) 为准，单项说明来自 [config/tweaks.json](https://github.com/yasewang1337-svg/winutil-cn/blob/main/config/tweaks.json)。

这些是选择起点，不保证所有电脑都需要修改。系统版本、现有配置与单位管理策略可能影响结果。

## 查看并运行

1. 在“优化”页选择方案或逐项勾选。
2. 点击 **查看并运行**，阅读具体改动及恢复限制。
3. 确认执行，结束后查看 **本次设置结果**。

如果勾选创建还原点，它会排在本次其他设置之前执行。创建或确认还原点失败时，本批后续设置和 DNS 修改会停止。没有勾选时，不会自动为每批创建 Windows 系统还原点。

有些改动需要重启资源管理器、注销或重启电脑后生效。结果窗口按项目报告，不能仅凭进度到达末尾判断全部生效：

| 状态 | 含义与下一步 |
| --- | --- |
| 完成 | 登记的设置已写入，或新的还原点已确认；按项目说明检查效果 |
| 失败 | 发生错误；已尝试的修改可能部分生效，查看原因与历史记录 |
| 跳过 | 本项没有执行，例如还原点失败后的后续项目或没有可恢复记录 |
| 待确认 | 脚本或 DNS 命令已结束，但效果没有逐项核验，需要检查实际状态 |
| 部分完成 | 例如保留了已自定义的服务启动方式，或只恢复了有快照的部分；阅读具体说明 |

## 操作历史与真实恢复

点击 **操作历史**，或在首页选择 **查看设置操作历史**，可查看最近的设置记录和修改前的值。记录存放在：

```text
%LOCALAPPDATA%\WinUtil\TweakHistory
```

执行登记的注册表和服务启动配置变更前，工具先保存修改前状态。如果读取或保存快照失败，该设置会在开始修改前停止。

恢复方法：

1. 在“优化”页勾选需要恢复的项目。
2. 点击 **恢复所选设置**，核对范围后确认。
3. 检查恢复结果。每项使用最近一条尚未撤销的记录；没有记录的项目会跳过。

恢复会覆盖这些记录项的当前值。如果操作之后又手动修改了同一项，先核对历史记录。恢复中途失败时，修复原因后可以重试，已经恢复的记录项会跳过。

| 可以按记录恢复 | 不在完整恢复范围内 |
| --- | --- |
| 注册表值原先是否存在、数据与类型 | 旧版本没有记录的操作 |
| 服务启动方式与延迟启动设置 | 服务当时的运行或停止状态 |
| 本次实际尝试修改且仍有有效记录的上述项目 | 已卸载应用、清理文件、脚本其他效果、DNS 和电源计划 |

新增的空注册表键可能保留。程序不会用通用默认值冒充这台电脑的历史状态；设置历史也不包含个人文件或应用内部配置备份。Windows 系统还原是另一种恢复工具，需要在 Windows 中操作。

## 个性化开关

个性化区域的开关会尝试应用开启或关闭目标，并读回状态；它们不是“先勾选再运行”的方案复选框。关闭开关是一项新的设置操作，不等于按历史撤销。受支持的注册表改动仍会保存原值。

图形界面导入清单不会自动切换这些开关。要按记录恢复，请使用前述恢复入口。

## DNS 与其他独立工具

DNS 下拉框中的 **Default** 表示本次不修改 DNS；**DHCP** 会恢复自动获取服务器地址。选择其他提供商后，当前流程会修改所有处于连接状态的网卡，包括可能的 VPN 网卡。

确认窗口会展示 DNS 范围。当前设置历史不保存原 DNS，执行结束也没有逐网卡核验，因此需要在 Windows 网络设置中确认结果；不要依赖“恢复所选设置”恢复 DNS。

页面还提供 O&O ShutUp10++ 和电源计划等独立工具入口。它们的其他效果不由这里的设置历史完整恢复。当前“移除卓越性能”操作调用 Windows 重置默认电源计划，会影响已有自定义电源计划；有自定义配置时应先核对。

## 自动化与问题反馈

命令行 `-Preset` / `-Config` 是执行入口。无人值守模式支持软件操作及可记录的基础注册表设置；含脚本、服务、预装应用移除、DNS 或系统功能的复杂操作需回图形界面确认。Advanced 包含还原点脚本，应在图形界面使用。

遇到失败时，请记录项目名称、版本、Windows 版本和结果中的错误内容，到[本项目 Issues](https://github.com/yasewang1337-svg/winutil-cn/issues)反馈。首次使用步骤见[快速上手](../getting-started/)。
