在软件页面集中选择需要的应用，查看计划后安装、更新或卸载。WinUtil CN 通过 WinGet 或 Chocolatey 执行，实际可用性取决于软件源、安装程序和本机状态。

## 找到软件并核对选择

按 `Ctrl + F` 搜索软件名称、介绍或软件包 ID。列表上方会显示匹配数量与已选数量；没有匹配时会给出提示，不会把之前的勾选清空。

使用 **仅看已选** 集中检查清单，也可以继续输入关键词查找其中的某项。**清除筛选** 恢复完整列表，**更多操作 → 清除选择** 才会取消勾选。列表上方的 **已选应用** 弹层支持滚动和逐项移除；软件较多时也能查看完整清单。

每行显示软件名称和用途摘要。鼠标停在名称、勾选框、用途或行内留白上，都能看到同一份完整介绍及可用的软件包 ID。右键打开 **安装 / 升级此软件**、**卸载此软件**、**访问软件官网**；键盘聚焦软件后也可按菜单键或 `Shift + F10` 打开，按 `Esc` 关闭。打开菜单不会执行任务，安装和卸载仍需确认。

**安装 / 升级…**、**卸载…** 是针对当前勾选的常用操作；**组合推荐** 提供按用途挑选的软件清单。折叠分类、勾选已装软件、整批升级和查看结果统一放在 **更多操作** 中。来源可在命令栏选择 WinGet 或 Chocolatey。

{{< tabs >}}

  {{< tab name="安装与更新" selected=true >}}
    * 选择你想安装或升级的应用。
        * 对于当前尚未安装的程序，此操作会安装它们。
        * 对于已经安装的程序，由包管理器判断可用更新或跳过。
    * 点击安装/升级所选按钮，核对弹出的软件清单与操作范围后确认执行。

  {{< /tab >}}

  {{< tab name="全部升级" >}}
    * 打开“更多操作 → 查看全部升级操作”，先阅读范围说明再确认。
    * 此入口尝试升级包管理器可识别的软件，范围不限当前勾选；未知版本、固定版本等情况可能被跳过。它只提供整批结果和日志，不是逐软件待更新列表。

  {{< /tab >}}

  {{< tab name="卸载" >}}
    * 选择你想卸载的程序。
    * 点击卸载所选按钮，核对清单后确认移除。

  {{< /tab >}}

  {{< tab name="勾选已安装应用" >}}
    * 点击“更多操作 → 勾选已装应用”。
    * 扫描当前所选包管理器可识别、且能匹配软件目录的已安装项目，并将它们加入当前勾选；原有选择会保留。
    * 可用“仅看已选”核对清单；扫描本身不会安装或卸载。

  {{< /tab >}}

  {{< tab name="清除选择" >}}
    * 点击“更多操作 → 清除选择”。
    * 这会清空当前所有的勾选。

## 查看结果与重试

所选软件的安装或卸载会逐项显示成功、失败、跳过或需要重启，以及包管理器返回的原因。存在失败项时可以仅重试失败项，已成功的软件不会在这次重试中重复处理。结果以退出码为依据，不代表所有应用内部功能都已验证。

结果列表优先列出失败项。选中软件后可以阅读完整原因、包管理器、退出码及日志路径，也可以复制所选详情。关闭窗口后，点击软件页的 **更多操作 → 查看上次结果** 可重新打开当前会话的最新软件结果；查看本身不执行操作，从这里重试会再次显示确认清单。重新启动程序后不会自动加载上次会话，原日志文件仍保留。

结果窗口可打开日志目录 `%LOCALAPPDATA%\WinUtil-CN\Logs\Packages`。更新或卸载不提供自动版本回退；需要重启时先保存工作，再按提示处理。

> [!TIP]
> 找不到软件时，先清除筛选，再换用名称、介绍中的关键词或完整软件包 ID。目录不包含所有可通过包管理器安装的应用。

> [!NOTE]
> “勾选已装应用”使用偏好中选择的 WinGet 或 Chocolatey；无法被该包管理器识别或未匹配软件目录的应用可能不会被勾选。

> [!IMPORTANT]
> 在卸载或升级应用之前，请先关闭正在运行的程序。某些包可能仍会要求输入，或在其来源不可用时失败。
