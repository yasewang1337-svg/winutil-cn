# WinUtil CN 中文装机与维护助手

适合刚买电脑、刚重装 Windows，或希望集中管理常用软件与设置的人。先选择用途、查看改动，再执行；普通使用可以从 EXE 启动，无需输入命令。

## 三步开始

1. **下载中文版**：前往[最新发布页](https://github.com/yasewang1337-svg/winutil-cn/releases/latest)，下载 **WinUtil-CN.exe**。
2. **打开并选择用途**：双击 EXE，按 Windows 提示授予管理员权限。在首页选择 **选择装机软件**、**打开软件管理** 或 **查看基础设置**。
3. **核对后执行**：选择软件或设置，查看确认窗口中的具体范围，再开始执行；完成后查看逐项结果，需要时打开日志或设置历史。

EXE 内嵌本版本脚本，使用 Windows 自带的 PowerShell 5.1。首次准备包管理器、下载安装软件和更新仍需要联网；单文件启动不代表所有功能可以离线使用。

## 使用环境

- Windows 11。
- 系统级修改需要管理员权限。
- 下载、安装和更新需要能访问对应软件源。
- 脚本也支持 PowerShell 5.1 / 7；正常使用 EXE 不必另装 PowerShell 7。

## 从首页完成常见任务

| 想做什么 | 入口与步骤 |
| --- | --- |
| 给新电脑装软件 | **选择装机软件** → 打开组合 → 调整候选 → **加入已选清单** |
| 安装或升级所选软件 | 安装页勾选软件 → **查看并安装/升级** → 核对计划 → **开始执行** |
| 卸载软件 | 安装页勾选软件 → **查看并卸载** → 核对范围后执行 |
| 调整系统设置 | **查看基础设置** → 查看勾选项 → **查看并运行** |
| 查看设置记录 | 首页 **查看设置操作历史**，或优化页 **操作历史** |
| 保存下次装机要用的选择 | 首页 **保存当前清单**；下次使用 **导入装机清单** |
| 查找修复工具 | 首页 **查看系统修复工具**，再按具体故障选用 |

首页入口用于导航或选择项目，不会因为点开卡片就开始安装或修改系统。中文搜索支持按软件名称和介绍查找。

## 装机组合怎样选择

组合提供用途说明与可调整的候选。比如“日常办公”默认推荐微信、WPS，钉钉、飞书和会议软件留给你按单位要求选择；浏览器、通讯平台和密码管理器不默认全选。

确认组合只会把勾选项加入安装页。取消不影响原来的选择；已有安装页勾选会保留，可以回安装页取消。

组合窗口的安装状态来自当前会话已有缓存。“尚未确认安装状态”不等于未安装。检测到已安装的软件仍可选择更新，但是否有可用更新，以包管理器实际结果为准。

完整候选见[软件组合推荐](../recommendations/)。

## 读懂软件操作结果

安装或卸载所选软件前，会显示名称、软件包 ID 和使用的包管理器。安装、更新会联网，首次使用 WinGet 还可能需要准备包管理器；确认窗口会说明这些操作。选择 Chocolatey 时须先按[官方指南](https://chocolatey.org/install)完成安装，本工具不再自动执行其远程初始化脚本；已有 Chocolatey 的软件管理功能保留。

完成后的 **软件操作结果** 会分别显示成功、失败、已跳过、需要重启，以及中文原因、退出码和日志路径。有失败项时，可以选择 **仅重试失败项**；重试会创建新的日志目录。

**查看全部升级操作** 的范围不限当前勾选，可能包含本工具目录以外、包管理器可识别的软件。这个入口只预览整批操作范围，不提供逐软件待更新列表；结果是整批退出结果及原始日志，也不提供整批失败自动重试。

软件日志默认位于：

```text
%LOCALAPPDATA%\WinUtil-CN\Logs\Packages
```

每次运行有独立目录，含 results.json 和各软件的输出、错误日志。结果窗口的 **打开日志文件夹** 可以直接进入。本工具不提供软件版本回退或应用内部设置的备份恢复。

## 系统设置与恢复范围

图形界面的方案按钮只负责勾选，不会立刻执行：

| 方案 | 当前内容 |
| --- | --- |
| 基础设置（Minimal） | 减少推荐应用、增加任务栏的结束任务入口 |
| 标准（Standard） | 在基础设置上增加活动历史策略、关闭 Windows 更新对等传输 |
| 高级（Advanced，仅图形界面） | 在标准方案上增加创建还原点和经典右键菜单 |

这些方案不默认包含批量卸载应用或禁用服务。仍应在 **查看并运行** 的确认窗口核对每项影响；效果取决于系统版本和现有配置。部分脚本操作会显示“待确认”，表示还需要检查实际效果。

本版本执行已登记的注册表或服务启动配置变更前，会保存修改前的真实值。要恢复，在优化页勾选项目，点击 **恢复所选设置**：

- 每项使用最近一条尚未撤销的记录；没有记录就跳过，不用通用默认值覆盖原设置。
- 可恢复已记录的注册表值及其类型、存在状态，以及服务启动方式和延迟启动设置；不会恢复服务当时的运行或停止状态。
- 已删除应用、清理的文件以及脚本的其他改动不在完整恢复范围内。旧版本执行但没有记录的改动也无法精确恢复。

记录保存在 `%LOCALAPPDATA%\WinUtil\TweakHistory`。不要把设置历史当作个人文件备份。执行应用删除、文件清理等操作前，应确认保留了需要的数据；Windows 系统还原是独立的恢复工具。

## 保存与导入清单

首页 **保存当前清单** 导出当前选择，以便下次装机复用。清单不包含安装包、个人文件或应用内部设置。

图形界面 **导入装机清单** 会先校验项目 ID，再让你确认是否替换当前勾选。取消、格式错误或未知项目不会覆盖原选择；导入不会自动安装软件、运行设置或切换开关。

命令行 `-Config` 是自动执行入口，行为与图形界面导入不同；不要为了查看一个不熟悉的清单而使用它。

## 脚本与自动化入口

已经习惯命令行的用户，可以从同一发布页下载 `winutil-cn.ps1` 与 `SHA256SUMS.txt`，先计算脚本哈希，与清单对应条目核对：

```powershell
Get-FileHash .\winutil-cn.ps1 -Algorithm SHA256
```

确认来源、内容和哈希后，在管理员 PowerShell 中运行 `& .\winutil-cn.ps1`。遇到策略拦截或杀毒告警时，先看[安全告警说明](https://github.com/yasewang1337-svg/winutil-cn/blob/main/docs/SECURITY.md)。非管理员会话中的远程内存脚本不再自动下载后提权。

命令行 `-Preset` / `-Config` 用于执行配置，使用前先检查内容；自动模式仅支持软件操作及可记录的基础注册表设置（含受支持的开关）；脚本、服务、预装应用移除（Appx）、DNS 和系统功能等复杂操作需要回图形界面核对。执行失败会报告错误，不会显示全部完成。

英文上游入口和开发信息见 [ChrisTitusTech/winutil](https://github.com/ChrisTitusTech/winutil)，中文版本的默认下载与问题反馈均在本仓库。

## 遇到问题

启动失败时先记录所用版本和启动方式。可检查以下位置：

- 启动错误：`%TEMP%\winutil-cn-error.log`。
- 一般运行日志：`%LOCALAPPDATA%\winutil\logs`。
- 软件任务：`%LOCALAPPDATA%\WinUtil-CN\Logs\Packages`。

如果下载失败，确认能够访问 GitHub 发布页及对应软件源。软件失败时先阅读结果原因；不要把已完成项目再次全部执行。

在[本项目 Issues](https://github.com/yasewang1337-svg/winutil-cn/issues)反馈时，提供版本、Windows 版本、启动方式、失败步骤与相关错误段落。发布日志前可删去个人路径等不需要公开的信息。
