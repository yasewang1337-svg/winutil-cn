装机组合把常见软件整理成候选清单。点击组合后先看用途、调整勾选，再加入安装页；不需要把一组软件全部安装。

## 三步使用

1. 从首页点击 **选择装机软件**，或打开 **安装** 页，再点击需要的组合。
2. 在预览窗口查看用途、软件说明与已知安装状态，保留需要的项目，点击 **加入已选清单**。取消或关闭窗口不会改变原来的选择。
3. 在安装页核对总清单，点击 **查看并安装/升级**，确认操作计划后执行。下载软件仍需要联网。

组合采用少量默认推荐；浏览器、通讯平台、网盘和密码管理器不预选。已有安装页勾选会保留，可回安装页取消。已经检测到安装的软件仍显示在候选中，可按需勾选更新。

**安装状态的含义**：组合预览只读取当前会话已有的安装缓存，不会为打开窗口而安装包管理器或联网扫描。缓存里找到的项目显示已安装；其余显示“尚未确认安装状态”，不能据此认定电脑没有安装。

## 国内组合

| 组合 | 默认推荐 | 其他候选与选择建议 |
| --- | --- | --- |
| 日常办公 | 微信、WPS Office | QQ、钉钉、飞书、腾讯会议、搜狗输入法。按单位要求选择协作平台；已有办公软件或习惯系统输入法，可以取消相应推荐 |
| 影音娱乐 | 不预选 | 网易云音乐、哔哩哔哩、爱奇艺、腾讯视频、迅雷。选择自己常用的平台 |
| 网盘与远程 | 不预选 | 百度网盘、夸克网盘、ToDesk、夸克浏览器。按已有账号选择网盘，需要远程协助时再选 ToDesk |
| 效率创作 | Snipaste | uTools、PicGo、Xmind。分别用于快捷启动、图片上传和思维导图 |

## 国际组合

| 组合 | 默认推荐 | 其他候选与选择建议 |
| --- | --- | --- |
| 开发环境 | VS Code、Git | Node.js、Python、Docker Desktop。按项目添加运行时和容器工具 |
| 选择浏览器 | 不预选 | Chrome、Firefox、Brave、Edge。通常选择一个常用浏览器即可，也可继续使用系统已有浏览器 |
| 影音媒体 | VLC | OBS Studio、ShareX、K-Lite Codec Pack、Audacity。按录屏、截图、解码和音频编辑需要选择 |
| 通讯协作 | 不预选 | Discord、Telegram、Slack、Zoom、Signal。按联系人或团队使用的平台选择 |
| 系统必备 | 7-Zip | Files、Notepad++、qBittorrent、Rufus。按文件管理、文本编辑、下载和制作启动盘的需要选择 |
| 隐私安全 | 不预选 | Bitwarden、Proton Pass、Signal、LibreWolf、Mullvad Browser。密码管理器通常选择一种 |

如果默认推荐项已经被当前缓存识别为已安装，预览不会再次自动勾选它；仍然可以手动选择。是否存在可用更新，以实际包管理器结果为准。

## 安装后的结果

安装或卸载所选软件后，结果窗口会逐项列出成功、失败、已跳过、需要重启等状态、中文原因和日志位置。存在失败项时，可以点击 **仅重试失败项**。组合本身只负责选择，不决定第三方软件的账号、付费内容或安装器行为。

**查看全部升级操作** 是另一种整批操作，范围不限当前勾选。它先说明范围再执行，不提供逐软件待更新列表；完成后提供整批退出结果和原始日志。

要保存自己的组合，可回首页点击 **保存当前清单**；下次使用 **导入装机清单**。清单保存的是所选项目，不包含安装包、个人文件或应用内部设置。

候选与推荐由 [config/bundles.json](https://github.com/yasewang1337-svg/winutil-cn/blob/main/config/bundles.json) 维护。MCP 保留完整的候选 apps 列表；defaultApps 用于图形界面的初始推荐，不表示自动批准安装。
