面对几百个应用不知道装哪些？这里按**地区（国内 / 国际）× 使用场景**整理了策展式组合，照着勾就是一套顺手的环境。

> [!TIP]
> 在**安装**标签页按 `Ctrl + F` 搜应用名即可快速定位并勾选。装完点「安装/升级所选」。

---

## 🇨🇳 国内组合

### 日常办公
国内主流办公通讯全家桶——聊天、协作、文档、输入法一步到位。

- 微信、QQ、WPS Office、钉钉、飞书、腾讯会议、搜狗输入法

### 影音娱乐
听歌、追剧、看视频、下载，国内平台一网打尽。

- 网易云音乐、哔哩哔哩、爱奇艺、腾讯视频、迅雷

### 网盘与远程
云存储 + 远程控制 + 极简浏览器，居家办公 / 传文件常用。

- 百度网盘、夸克网盘、ToDesk、夸克浏览器

### 效率创作
启动器、截图贴图、图床、思维导图，提升日常效率。

- uTools、Snipaste、PicGo、Xmind

## 🌍 国际组合

### 开发环境
编辑器 + 版本控制 + 运行时 + 容器，开箱即用的开发工作站。

- VS Code、Git、Node.js、Python、Docker Desktop

### 浏览器矩阵
主流与注重隐私的浏览器，按需选用。

- Google Chrome、Firefox、Brave、Edge

### 影音媒体
全能播放器、录屏、截图、音频处理与解码包。

- VLC、OBS Studio、ShareX、K-Lite Codec Pack、Audacity

### 通讯协作
国际主流即时通讯与会议工具。

- Discord、Telegram、Slack、Zoom、Signal

### 系统必备
压缩、文件管理、文本编辑、下载、启动盘制作，重装必备。

- 7-Zip、Files、Notepad++、qBittorrent、Rufus

### 隐私安全
密码管理、加密通讯、注重隐私的浏览器。

- Bitwarden、Proton Pass、Signal、LibreWolf、Mullvad Browser

---

## 怎么用

1. 打开 **安装** 标签页。
2. 按上面某个组合的清单，逐个勾选（`Ctrl + F` 搜名字最快）。
3. 点底部「**安装/升级所选**」，它们会依次静默安装，不带捆绑软件。

> [!NOTE]
> 这些组合是**建议起点**，不是必须全装。按需增减即可。组合清单由 `config/bundles.json` 维护，后续会支持在界面里一键套用整套组合。
