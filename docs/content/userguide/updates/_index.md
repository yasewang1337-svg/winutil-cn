从左侧进入 **Windows 更新**。页面按恢复、延迟和禁用三种配置纵向排列，先阅读每项影响，再选择对应按钮。窄窗口或放大字号时，可以向下滚动查看完整说明和操作。

## 三种配置的区别

| 配置 | 作用 | 使用边界 |
| --- | --- | --- |
| **恢复更新配置** | 移除工具涉及的更新策略，尝试恢复相关服务与计划任务。 | 不会恢复修改前的个人或组织配置，也不是整个系统的出厂重置。 |
| **延迟更新**（应用延迟策略） | 尝试将功能更新延迟 365 天、质量更新延迟 4 天，并调整驱动更新和重启相关设置。 | 质量更新包含安全修复；此配置不是“只接收安全补丁”。 |
| **禁用更新** | 尝试停用相关更新服务、任务和策略。 | 会影响正常获取系统修复，实际效果也受 Windows 版本和设备管理策略影响。 |

这三个入口修改的是系统更新配置。只想检查可用更新、暂时暂停更新或设置活动时间时，可以直接使用 **Windows 设置 → Windows 更新**。

## 切换与恢复

应用后按页面和控制台提示处理，必要时重启，再到 Windows 设置中确认实际更新状态。延迟天数使用现有 Windows 更新设置项，是否生效取决于系统版本和策略；不能保证系统绝不自动重启。

从禁用状态恢复时，先使用 **恢复更新配置** 并检查相关服务和 Windows 更新状态；直接切到 **延迟更新** 不能保证已经恢复先前停用的服务和任务。三种配置的全部往返切换尚未完成真机验证。

**系统配置**页的更新组件修复是另一个入口，可能涉及网络组件与具体更新策略。它与本页的恢复更新配置作用不同，范围见 [功能与修复](../features/)；已有调查记录见 [更新调查](https://github.com/yasewang1337-svg/winutil-cn/blob/main/docs/UPDATE-AUDIT-2026-10.md)。
