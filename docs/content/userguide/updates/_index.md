Winutil 提供三种更新模式，让你自行决定系统上的 Windows 更新要被管得多严：

切换模式会调整系统级的 Windows 更新行为，效果受 Windows 版本、现有策略和设备管理限制影响。当前三个模式尚未完成所有往返切换验证：尤其从“禁用”直接切到“推荐”，不能保证已恢复服务和任务。通常优先在 Windows 设置中管理更新；问题与后续计划见[更新调查](https://github.com/yasewang1337-svg/winutil-cn/blob/main/docs/UPDATE-AUDIT-2026-10.md)。

{{< image src="images/screenshots/updates-tab-new" alt="Winutil 中的更新标签页" >}}

- **Default（Out of the Box）Settings（默认/开箱设置）**：尝试移除相关更新策略并恢复更新服务和任务
- **Security（Recommended）Settings（安全/推荐设置）**：优先保证稳定性，同时仍接收安全更新
- **Disable ALL Updates（禁用全部更新）**：尝试停用相关更新机制，不能保证所有版本或受管理设备均生效

### 默认（开箱）设置

- **它做什么**：恢复默认的 Windows 更新配置。
- **适合谁**：希望让 Windows 正常管理更新的系统。
- **说明**：它会修改指定的更新策略、服务和任务，不会恢复修改前的个人或组织配置。本轮已移除全局安全模板重置。配置页的更新组件修复仍可能重置网络组件和具体更新策略，应先保留必要配置并确认影响，不能视为完整恢复系统默认。

### 安全（推荐）设置

- **它做什么**：套用一套更保守、面向大多数用户设计的更新策略。
- **功能更新**：当前代码尝试写入延迟 **365 天** 的旧 UX 设置。
- **质量更新**：当前代码尝试写入延迟 **4 天** 的旧 UX 设置，不能把它解释为只延迟安全补丁。
- **限制**：上述值在当前 Windows 上的实际效果尚待完整验证；现有重启策略有适用条件，不能保证绝不自动重启。三个模式的兼容性修复是后续工作。

### 禁用全部更新（不推荐！）

- **它做什么**：禁用所有 Windows 更新。
- **适合谁**：高度受控或特殊用途、必须暂时保持更新关闭的系统。
- **警告**：这会让系统得不到安全补丁，显著增加安全风险。
- **建议**：除非你完全理解其中的取舍、并有明确理由，否则请避免使用这个模式。
